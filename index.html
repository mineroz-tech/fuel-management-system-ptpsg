📘 Petunjuk Penggunaan Dashboard

panduan singkat
1
Navigasi Sidebar
Klik menu di sidebar kiri untuk lompat ke bagian yang diinginkan — Ringkasan, Stock Fuel, Tren, Distribusi, Efisiensi, Leaderboard, Heatmap, sampai Log Transaksi. Menu aktif otomatis ke-highlight sesuai posisi scroll. Klik ikon panah di sebelah logo untuk menyembunyikan/menampilkan sidebar dan memperluas area kerja.
2
Filter Data
Gunakan filter tanggal (Dari–Sampai), Shift, Kategori Unit, atau kolom pencarian di bagian atas untuk mempersempit data. Semua KPI, grafik, dan tabel di seluruh dashboard otomatis menyesuaikan dengan filter yang aktif. Klik "Reset Filter" untuk kembali ke tampilan penuh.
3
Upload Excel Baru
Klik "⬆ Upload Excel Baru" di header (atau di sidebar) untuk memuat file bulan berikutnya. File akan dibaca langsung di browser Anda — tidak dikirim ke internet — selama struktur sheet "Fuel Usage" & "FUEL CONSUMPTION" sama seperti template asal.
4
Tabel Interaktif
Klik judul kolom pada tabel Efisiensi atau Log Transaksi untuk mengurutkan data (klik lagi untuk membalik urutan). Tabel Log Transaksi mendukung paginasi — gunakan tombol « ‹ › » di pojok kanan bawah tabel untuk berpindah halaman.
5
Export Laporan
Klik "⬇ Export Laporan" untuk membuka dialog cetak browser — pilih "Save as PDF" untuk menyimpan laporan rapi tanpa sidebar/filter, siap dikirim atau diarsipkan.
6
Mode Gelap / Terang
Gunakan switch "Dark / Light" di bagian bawah sidebar untuk mengganti tema tampilan sesuai preferensi atau kondisi pencahayaan ruangan Anda.
Catatan: dashboard ini berjalan 100% offline di browser — tidak membutuhkan koneksi internet setelah semua file (dashboard.html, app.js, embedded_data.js, stock_data.js, chart.umd.min.js, xlsx.full.min.js) berada dalam satu folder yang sama.
